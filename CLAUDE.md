# Контекст для Claude Code

Сайт-лендинг «АРКА 123» (тестовое задание вайбкодера для Медиа Лайн). Next.js 15 App Router, TypeScript strict, без UI-библиотек.
Репозиторий — github.com/Senkoslav/arka, ветка `main`; деплой — Vercel из GitHub, настройки в `vercel.json`.

- Язык интерфейса, комментариев и сообщений коммитов — русский.
- Стили — только `app/globals.css` (обычный CSS, токены в `:root`, тёмная тема через `prefers-color-scheme` и `[data-theme]`). Tailwind не используется. Цвета — только переменными: тёмные секции (`--deep`, `--deep-2`, `--deep-line`, `--footer`) и текст на них (`--on-dark`, `--on-dark-soft`, `--on-dark-muted`, `--on-dark-faint`). Зоны нажатия — от 44 px на сенсорных экранах.
- 3D: `lib/arkaScene.ts` — императивный модуль three.js **0.147** (не обновлять без перенастройки света). React-обёртка — `components/SceneProvider.tsx`; сцена грузится динамическим `import()` только на клиенте.
- Анимации — GSAP 3 + ScrollTrigger; в компонентах использовать `gsap.context()` и откатывать в cleanup.
- Размеры зала (123 м², потолок 4,5 м, окна 4 × 3,5 м) — из ТЗ; вместимость считается в `lib/layouts.ts`, не хардкодить числа.
- Уважать `prefers-reduced-motion` во всех новых анимациях.
- Проверка перед коммитом: `npx tsc --noEmit && npm run build`. Dev-сервер перед сборкой остановить — оба пишут в `.next`.

## Гид Анна (фирменный персонаж)

- Позы — `public/img/guide-<имя>.webp`, только через `npm run guide -- <имя>=путь.png` (`scripts/guide-poses.mjs`). Вручную не редактировать: скрипт выравнивает все позы по ступням и оси тела, зеркалит их и возвращает брошь-логотип в прямое положение.
- Холст поз (константы `CW/CH/AX/FEET`, выход 610×1200) общий для всех поз. Если его менять — перегенерировать все позы и поправить в `globals.css` `aspect-ratio` у `.figure-wrap` и положение `.bubble` (привязано к голове: ~57–81% ширины кадра, подбородок ~11% высоты).
- Шаг → поза: `GUIDE_POSES` в `components/Tour.tsx`. Поза с планшетом (`guide-tablet.webp`) ещё не сделана; когда появится — на шаг 4 (вид на Библиотеку + «Забронировать зал»).
- Раскладка прогулки: шире 980 px — текст шага слева, гид справа, реплика у щеки; до 980 px — текст сверху, гид снизу справа, реплика слева от кадра (не закрывает вытянутую руку); до 760 px на первом экране реплика скрыта до начала прокрутки (`data-intro`), иначе закрывает кнопки.

## Зависимости

- `postcss` переопределён в `overrides` (Next 15 тянет уязвимую 8.4.31). `npm audit fix --force` не запускать — он ставит Next 16.
- Шрифты — локально через Fontsource, без Google Fonts: сборка не зависит от доступа к сети.
