# АРКА 123 — сайт зала напротив Библиотеки

Тестовое задание «AI-разработчик концепций и дизайна / Vibe coder» для Медиа Лайн.
Вымышленная компания: аренда зала 123 м² под мастер-классы, Минск, ул. Мстиславца, 10. Слоган — «Встречаемся напротив Библиотеки».

**Сайт:** https://arka-beta-two.vercel.app · **Код:** https://github.com/Senkoslav/arka

**Сроки:** 5 дней, 13–17 октября 2026 — понемногу каждый день параллельно с основной работой, основной объём сделан 17 октября.

**Стек:** Next.js 15 (App Router) · React 19 · TypeScript · three.js r147 · GSAP 3 + ScrollTrigger · Fontsource (шрифты без Google).

## Запуск

Рекомендуемая версия Node.js — 24 (`.nvmrc`); Next 15 поддерживает Node 18.18 и новее.

```bash
git clone https://github.com/Senkoslav/arka.git && cd arka
npm install
npm run dev        # http://localhost:3000
npm run build      # продакшен-сборка (страница статическая)
```

## Деплой на Vercel

1. На vercel.com → **Add New → Project** → импортируйте репозиторий `Senkoslav/arka`.
2. Deploy. Настройки менять не нужно — всё задано в `vercel.json`: установка через `npm ci`, регион `fra1` (ближайший к Минску), заголовки безопасности и кэш картинок на час.
3. Переменные окружения не обязательны. Для ссылок в превью соцсетей на своём домене задайте `NEXT_PUBLIC_SITE_URL=https://ваш-домен`.

Каждый `git push` в `main` после подключения публикуется автоматически.

## Фирменный персонаж — гид Анна

Позы лежат в `public/img/guide-*.webp`:

| Шаг прогулки | Реплика | Поза |
|---|---|---|
| 0 | «Здравствуйте! Я Анна…» | `wave` — машет |
| 1 | Открытый зал 123 м² | `present` — жест ладонью |
| 2 | Потолок 4,5 м и светильники | `up` — указывает вверх |
| 3 | Арочные окна | `point` — указывает на окно |
| 4 | Вид на Библиотеку | `present` — до появления позы с планшетом (`tablet`) |

Соответствие шагов и поз — массив `GUIDE_POSES` в `components/Tour.tsx`; реплики и имя гида — массив `STEPS` там же.

Новая поза (PNG 1024×1536 с уже прозрачным фоном):

```bash
npm run guide -- tablet=~/Downloads/поза.png   # → public/img/guide-tablet.webp
```

Скрипт кладёт все позы на один холст: ступни и ось тела совпадают, поэтому при смене шага меняется только жест, фигура стоит на месте. Позы зеркалятся — гид стоит справа и показывает в зал, — а брошь-логотип возвращается в прямое положение, чтобы «123» читалось.

## Зависимости

- **three.js закреплён на 0.147.** Свет и тон-маппинг сцены настроены под «старую» модель освещения three.js (до r155). При обновлении нужно включить `renderer.useLegacyLights` или заново подобрать интенсивности света в `lib/arkaScene.ts`.
- **postcss переопределён на 8.5.28** (`overrides` в `package.json`). Next 15 тянет postcss 8.4.31 с известными уязвимостями, а `npm audit fix --force` предлагает только переход на Next 16. Переопределение закрывает уязвимости без мажорного обновления; `npm audit` — 0 уязвимостей.
