# АРКА 123 — сайт зала напротив Библиотеки

Тестовое задание «AI-разработчик концепций и дизайна / Vibe coder» для Медиа Лайн.
Вымышленная компания: аренда зала 123 м² под мастер-классы, Минск, ул. Мстиславца, 10.

**Стек:** Next.js 15 (App Router) · React 19 · TypeScript · three.js r147 · GSAP 3 + ScrollTrigger · Fontsource (шрифты без Google).

## Запуск

```bash
npm install
npm run dev        # http://localhost:3000
npm run build      # продакшен-сборка (страница статическая)
```

## Деплой на Vercel

1. Залейте проект в GitHub (`git push`).
2. На vercel.com → **Add New → Project** → выберите репозиторий. Framework определится как Next.js, настройки менять не нужно.
3. Deploy. Переменные окружения не обязательны; для правильных ссылок в превью соцсетей можно задать `NEXT_PUBLIC_SITE_URL=https://ваш-домен`.

Или без GitHub: `npm i -g vercel && vercel` из папки проекта.

## Как добавить фирменного персонажа

1. Сгенерируйте позы (по одной на шаг прогулки, прозрачный фон).
2. Положите в `public/img/` как `guide-0.webp` … `guide-4.webp`.
3. В `components/Tour.tsx` заполните `GUIDE_POSES`.
Имя гида и реплики — в массиве `STEPS` там же.

## Демо-данные

Цены, телефон, Telegram и отзывы — примеры (так и подписано на сайте). Реальные значения: `lib/pricing.ts`, `components/Booking.tsx`, `components/Sections.tsx`.

## Почему three.js 0.147

Свет и тон-маппинг сцены настроены под «старую» модель освещения three.js (до r155). При обновлении three нужно включить `renderer.useLegacyLights` или заново подобрать интенсивности света в `lib/arkaScene.ts`.
